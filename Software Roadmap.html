BRANCH 2.1

Excel — شاخه‌ی موازی

موازی · ادامه‌دار
چرا شاخه‌ی جدا؟ چون Excel ایستگاه نیست — جاده است. از روز اول شروع می‌شود و تا انتهای مسیر (و تا انتهای دوران کاری‌ات) ادامه دارد. یک Graduate در دفتر بیشتر از هر نرم‌افزار دیگری با Excel کار می‌کند.
مرحله‌ی اول — مبانی
محیط، References ($)، توابع پایه (IF, MIN, MAX, ROUND) — هم‌زمان با S0.
مرحله‌ی دوم — توابع طراحی
XLOOKUP / INDEX+MATCH برای جدول مقاطع، Data Validation، Conditional Formatting — هم‌زمان با S1 و S2.
مرحله‌ی سوم — Design Spreadsheet
ساخت اولین Design Sheet واقعی: ورودی، محاسبه، خروجی Pass/Fail — هم‌زمان با S3 و S4 و درس‌های Loading مسیر ۱.
خروجی این شاخه

TB-01 Load Takedown Spreadsheet برای Column B2 از Roof تا Foundation + یک Beam Design Sheet با چراغ Pass/Fail.

📁 خروجی: 2 فایل Excel + نسخه‌ی PDF برای Portfolio · فایل آموزشی: Software — Excel

S0

Drawing Reading — نقشه‌خوانی (pdf & dwg)

شروع شاخه‌ی 2.2
چرا اول؟ نقشه‌خوانی نرم‌افزار نیست، مهارت است — ولی همه‌ی نرم‌افزارهای بعدی روی آن سوارند. اگر ندانی SSL یا H16-200-B1 یعنی چه، هیچ نرم‌افزاری نجاتت نمی‌دهد.
اجزای هر نقشه
Title Block · Revision · Status Codes (ISO 19650) · Scale · North Arrow
انواع نقشه
GA Plan · Sections · Details · Foundation Plan · Schedules
Grids و Levels
Grid References · SSL / FFL / TOS / TOC / AOD · Setting Out
نقشه‌های Steel و RC
مقاطع UB/UC/PFC/SHS · اتصالات و جوش · Rebar Notation · BS 8666
مخفف‌ها و قراردادها
TYP · NTS · U.N.O. · C/C · انواع خط · Hatching · Cross-referencing
خروجی این ایستگاه

Drawing Decode Report: یک نقشه‌ی واقعی از Planning Portal بردار و تک‌تک علامت‌ها و مخفف‌هایش را رمزگشایی کن + واژه‌نامه‌ی شخصی‌ات را در Excel شروع کن.

📁 خروجی: 1 Report + شروع واژه‌نامه · زمان: ≈ 15–20 h · فایل آموزشی: Software — Drawing Reading

S2

شاخه‌ی 2.2
چرا اینجا؟ نیمه‌ی دوم نقشه‌خوانی: فایل‌های DWG. فقط 2D — و فقط در حد پایه؛ چون Revit جای آن را در مدل‌سازی گرفته ولی Details و نقشه‌های قدیمی هنوز DWG هستند.

S3

Revit — BIM Modelling

شاخه‌ی 2.2
چرا اینجا؟ پرتقاضاترین نرم‌افزار آگهی‌های شغلی UK. حالا که نقشه را می‌فهمی و کشیده‌ای، وقت مدل‌سازی است — Revit همان نقشه‌ها را از روی مدل خودکار تولید می‌کند.

خروجی
Views · Sheets · Schedules · Annotation · Export IFC / DWG / PDF
مفاهیم BIM

TB-01 Revit Model: کل ساختمان را مدل کن و از آن Sheets بگیر: GA Plans، Section، 3D View و یک Column Schedule.

📁 خروجی: Model + 4 Sheets (PDF) · زمان: ≈ 30–40 h · فایل آموزشی: Software 03 — Revit (بعداً)

S4

Tekla Structural Designer — Analysis & Design

پایان شاخه‌ی 2.2
چرا آخر؟ چون خطرناک‌ترین ایستگاه است: نرم‌افزار تحلیل بدون فهم مهندسی یعنی Garbage In, Garbage Out. این ایستگاه را شروع نکن تا وقتی در مسیر ۱ به Loading (P6) رسیده باشی.

📁 خروجی: Design Report + Comparison Table · زمان: ≈ 20–25 h · فایل آموزشی: Software 04 — TSD (بعداً)

قواعد پیشروی این مسیر

۱ — دو شاخه هم‌زمان: هر روز که روی شاخه‌ی 2.2 کار می‌کنی، Excel هم کنارش زنده است. لازم نیست جدا وقت بزرگی بگذاری — تمرین‌های Excel از دل همان ایستگاه‌ها درمی‌آیند.

۲ — قفل هماهنگی با مسیر ۱: S0 تا S3 را هر وقت خواستی برو؛ ولی S4 (TSD) قفل است تا وقتی در مسیر ۱ به P6 — Loading برسی. مدل‌سازی دانش سازه نمی‌خواهد، تحلیل می‌خواهد.

۳ — هر ایستگاه یک فایل آموزشی: مثل فایل‌های Phase در مسیر ۱، هر ایستگاه یک فایل درسی جدا دارد. تا الان: Software — Drawing Reading، Software 01 — Bluebeam و Software — Excel آماده‌اند؛ بقیه به ترتیب ساخته می‌شوند.

۴ — هیچ ایستگاهی بدون خروجی تمام نمی‌شود: خروجی هر ایستگاه همان لحظه وارد پوشه‌ی Portfolio می‌شود.
